Policy templates · __PRESETS__ roles · __AREAS__ areas

Policy templates for every role

Each template is a list of AI rules for one role or one area. Read the rules here, download them as a CSV file, edit the file in a spreadsheet and import it into the builder. The files are made in this tab and nothing is uploaded.

Edit and import

What happens to each row when you import the file

Open the file in any spreadsheet. Keep the id column as it is so Komainu can match each row to its rule.

01

Leave a row alone

The catalog rule stays on, with its coverage label.

02

Change a row

Your wording, level or area replaces the catalog rule and is listed under your rules.

03

Delete a row

The catalog rule is switched off.

04

Add a row

A row with an empty id becomes a rule of your own. Use source for the clause it comes from.
